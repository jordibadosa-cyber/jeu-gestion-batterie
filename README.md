# Jeu de gestion de batterie

Jeu pédagogique de pilotage énergétique en français et en anglais.

**Jouer : https://jordibadosa-cyber.github.io/jeu-gestion-batterie/**

Ce dépôt contient la version statique publiée sur GitHub Pages. Les sources complètes et la configuration de compilation sont disponibles dans [sources-jeu-gestion-batterie.zip](sources-jeu-gestion-batterie.zip).

Après extraction : installer Node.js 22 et pnpm 10, exécuter `pnpm install --frozen-lockfile`, puis `node github-pages/build.mjs`. Le site généré se trouve dans `github-pages/dist`.

Pages : jeu, documentation et quiz, chacun en français et en anglais.
